# Security policy

LarTycc is pre-alpha and has no supported release yet. Please do not open a
public issue for a vulnerability. Use GitHub's private vulnerability reporting
feature for this repository. Include affected revision, reproduction steps,
impact, and any suggested mitigation. Maintainers will acknowledge a complete
report within seven days and coordinate disclosure after a fix is available.

Security boundaries planned for later phases include plugin sandboxing,
validated project parsing, signed update metadata, model integrity checks, and
strict separation between untrusted AI output and executable project commands.
